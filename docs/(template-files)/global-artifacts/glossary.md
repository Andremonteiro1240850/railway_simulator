| **CLK**                               | **ADM**                             | Acronym for _Clerk_.                                                                                                                                                |
| **Agile Scrum**                       | **Scrum Ágil**                      | An iterative and incremental software development methodology that promotes adaptive planning evolutionary development, and continuous improvement through sprints. |
 | **Cargo**                             | **Carga**                           | Goods or passengers transported between stations in the simulation.                                                                                                 |
| **Carriages**                         | **Carruagens**                      | Train components designed to transport different types of cargo, such as passengers, mail, coal or steel.                                                           |
| **Cities**                            | **Cidades**                         | urban areas on the map that generate and consume resources like passengers, mail, and final products.                                                               |

| **Industries**                        | **Industria**                       | Economic entities on the map that produce and consume resources, classified into primary, transforming, and mixed industries.                                       |
| **junit**                             | **Junit**                           | A framework for unit testing in java, ensuring that individual code components function as expected.                                                                |
| **Locomotive**                        | **Locomotiva**                      | A powered vehicle that provides the traction needed to move trains; can be steam, diesel or electric.                                                               |
| **Map Editor**                        | **Editor de Mapa**                  | A tool for creating and modifying the game’s geographical layout, including placing cities and industries.                                                          |                                                                                                     
| **Minimal Viable Product (MVP)**      | **Menor Produto Viavel**            | The smallest functional version of the project that meets essential requirements, developed iteratively.                                                            |
| **Non-Functional Requirements**       | **Funções não Funcionais**          | Specifications that define system constraints such as security, performance, usability, and maintainability.                                                        |
| **Object-Oriented Programming (OOP)** | **Programação Orientada ao Objeto** | A programming paradigm based on objects that encapsulate data and behavior, promoting modularity and reusability.                                                   |
| **Persistence**                       | **Persistência**                    | The ability of the application to store and retrieve data across different sessions, achieved through object serialization.                                         |
| **Player**                            | **Jogador**                         | A system user who interacts with the simulation by managing railway networks and optimizing transport operations.                                                   |
| **Primary Sector Industry**           | **Setor Industrial Primário**       | An industry that generates raw materials like coal, iron ore, or agricultural products.                                                                             
| **Railway Line**                      | **Linha de comboio**                | **A connection between two stations that enables train movement and cargo transportation.                                                                           |
| **Routes**                            | **Rotas**                           | Predefined paths along which trains operate, specifying stations and cargo to be transported.                                                                       |
| **Scenario Editor**                   | **Editor de Cenário**               | A tool allowing users to define operational constraints and historical settings within a game map.                                                                  |
| **Simulation Tool**                   | **Simulação**                       | The core software component that allows users to create and interact with railway networks dynamically.|
| **Stations**                          | **Estações**                        |Railway hubs where cargo is collected and delivered, categorized into depots, stations, and terminals based on capacity and functionality.|
| **Steel Mil**                         | **Fábrica de Aço**                  |A transforming industry that converts raw materials like iron ore and coal into steel.|
| **System Users**                      | **Sistema de Utilizadores**         |The different types of users interacting with the application, including editors and players.|
| **Test-Driven Development (TDD)**     | **Melhoria do Teste**               |A software development methodology where tests are written before the actual implementation to ensure correctness.|
| **Terminals**                         | **Terminais**                       |The largest type of station with the most extensive economic radius and highest operational cost.|
| **User Stories (US)**                 | **História dos Utilizadores**       |Short, structured descriptions of desired functionalities from the perspective of system users, guiding development priorities.|
| **Version Control**                   | **Versão de Controlo**              |– A system that tracks changes to code and documents, facilitating collaboration and maintaining historical revisions.|
| **Validation Rules**                  | **Regras de Validação**             |– Business logic constraints that ensure data integrity and correctness when entering or updating system information.|
| **Warehouse**                         | **Armazém**                         |A facility at a station where cargo is stored before being transported to its final destination.|
